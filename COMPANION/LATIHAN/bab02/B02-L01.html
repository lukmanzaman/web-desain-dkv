🛠️ Latihan Studio: Membedah Lalu Lintas Data (B02-L01)

Eksperimen memahami siklus Request-Response, resolusi DNS, dan status kode HTTP menggunakan DevTools Network Tab.

Langkah Eksperimen di Peramban:

  1. Buka Google Chrome atau Mozilla Firefox.
  2. Tekan F12 (atau Klik Kanan → Inspect) → Buka tab Network (Jaringan).
  3. Centang opsi Disable cache dan atur pembatasan kecepatan ke Fast 3G.
  4. Ketik alamat web berita terkemuka lalu tekan Enter.
  5. Amati berkas HTML yang pertama kali diunduh, lalu bagaimana CSS, Font, dan Gambar diminta menyusul secara paralel.

Daftar Status Kode HTTP Penting:

  • 200 OK : Permintaan berhasil dan berkas dikirimkan utuh.
  • 304 Not Modified : Berkas diambil dari memori cache lokal karena belum berubah.
  • 404 Not Found : Alamat URL salah atau berkas telah dipindahkan/dihapus.
