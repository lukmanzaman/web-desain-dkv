# Panduan Pengelolaan Situs — Kedai Kopi Senja

Selamat! Situs web studio Anda telah selesai dibangun dan tayang di URL resmi. 
Dokumen ini berisi panduan ringkas cara memperbarui konten bagi tim non-teknis.

## 📁 Struktur Berkas
- `index.html`: Berkas utama halaman muka (teks hero, menu, dan jam buka).
- `style.css`: Berkas warna tema dan tata letak.
- `gambar/`: Folder penyimpanan foto produk dan logo.

## ✍️ Cara Mengganti Jam Buka
1. Buka berkas `index.html` di editor teks.
2. Cari baris bertuliskan `<!-- Jam Operasional -->`.
3. Ganti teks jam sesuai jadwal baru, lalu simpan berkas.
