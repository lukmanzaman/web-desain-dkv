Silabus Mata Kuliah Desain Web DKV

Alur Pengerjaan Tugas Akhir

  1. Pengumpulan data dan wawancara pengguna
  2. Penyusunan arsitektur informasi dan peta situs
  3. Pembuatan wireframe dan prototipe kode HTML murni
  4. Evaluasi keterbacaan dan serah terima proyek

Struktur Modul Pembelajaran

  • Fondasi Kode Web
    • Anatomi Dokumen HTML5
    • Hierarki Teks dan Tipografi
  • Tata Letak Visual
    • Flexbox Satu Dimensi
    • Grid Dua Dimensi

Glosarium Istilah

Viewport
Area kanvas yang tampak di jendela peramban pengguna.
Wireframe
Kerangka struktural tata letak sebelum diberikan dekorasi rupa.
