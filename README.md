## 📖 Tentang Buku & Repositori

Buku **"Desain Web bagi Noncoder"** dirancang khusus untuk menjembatani dunia desain grafis/visual (khususnya mahasiswa Desain Komunikasi Visual / DKV, desainer grafis, UI/UX desainer, dan pemula non-programmer) dengan dunia web modern. 

Buku ini mengajarkan bagaimana menerjemahkan kepekaan estetika, hierarki visual, ritme tipografi, dan komposisi ruang ke dalam media peramban (*web browser*) secara mandiri menggunakan kode yang terstruktur, bersih, dan sesuai standar modern.

### Repositori ini memuat:
1. **71 Slide Presentasi (.pptx)** untuk kebutuhan pengajaran, kuliah, seminar, atau pembelajaran mandiri.
2. **71 Dokumen Slide PDF (Full)** dengan tata letak visual penuh.
3. **71 Dokumen PDF Versi Teks Ringkas** untuk pembacaan cepat, hemat kuota, dan aksesibilitas dokumen.
4. **Kode Pendukung (*Companion Code*)**:
   - `CONTOH/`: Berkas contoh kode implementasi per bab.
   - `LATIHAN/`: Latihan praktik mandiri dan tugas per bab.

---

```text
.
├── PPT/                  # Slide presentasi PowerPoint (.pptx) Bab 01 s.d. 71

```

## 🛠️ Petunjuk Penggunaan

### 1. Untuk Mahasiswa / Pembelajar Mandiri
- Buka slide materi (`.pptx` atau `.pdf`) untuk mempelajari konsep visual dan kaidah kodingnya.
- Buka folder `COMPANION/CONTOH/` untuk melihat bagaimana kode ditulis dan dijalankan secara nyata pada peramban.
- Kerjakan studi kasus pada folder `COMPANION/LATIHAN/` untuk menguji pemahaman dan membangun portofolio pribadi.

### 2. Untuk Dosen / Pengajar
- Berkas PowerPoint (`PPT/*.pptx`) dapat disesuaikan atau digunakan langsung sebagai materi ajar perkuliahan di kelas/laboratorium.
- Berkas PDF teks (`PDF-text-version/`) sangat cocok dibagikan melalui *Learning Management System* (LMS) seperti Google Classroom, Moodle, atau Canvas karena ukurannya yang sangat ringan dan mudah diunduh oleh mahasiswa.

### 3. Lingkungan Kerja yang Direkomendasikan
- **Editor Teks / Kode**: Visual Studio Code (VS Code), Cursor, atau Sublime Text.
- **Ekstensi Pendukung**: *Live Server* (untuk melihat perubahan halaman web secara *real-time*).
- **Peramban Modern**: Google Chrome, Mozilla Firefox, Microsoft Edge, atau Safari (lengkap dengan Developer Tools bawaan).
